# موقع السيرة الذاتية: بسنت رضا ربيع

موقع ثابت (HTML + CSS + JavaScript) بدون أي أدوات بناء أو خدمات مدفوعة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | محتوى الصفحة (النصوص الأساسية: النبذة، التعليم، التدريب) |
| `style.css` | التصميم والألوان (الألوان في أعلى الملف) |
| `script.js` | الإعدادات القابلة للتعديل: التواصل، المهارات، المشروعات |
| `assets/` | ضعي هنا صورتك الشخصية باسم `profile.jpg` |

## كيف أعدّل المعلومات؟

1. **الصورة الشخصية:** ضعي صورة باسم `profile.jpg` داخل مجلد `assets`. إن لم توجد الصورة يظهر الحرف «ب» مكانها.
2. **روابط التواصل:** افتحي `script.js` واكتبي بريدك وروابط LinkedIn وGitHub داخل قائمة `CONTACTS` (مثال: `value: 'https://github.com/username'`). الحقول الفارغة لا تظهر كروابط معطلة.
3. **المهارات:** القائمة الحالية مقترحة وتظهر بإطار منقط. انقلي ما درستِه فعليًا إلى `CONFIRMED_SKILLS` ليظهر كمهارة مؤكدة، واحذفي ما لا ينطبق من `SKILLS`.
4. **المشروعات:** استبدلي النماذج المؤقتة في `PROJECTS` بمشروعاتك الحقيقية (العنوان، الوصف، التقنيات، الرابط).
5. **نص التدريب والنبذة:** عدّلي النص مباشرة في `index.html`. يمكنك إضافة مدة التدريب وما تعلمتِه فعليًا.
6. **إخفاء الملاحظات المؤقتة:** بعد الانتهاء غيّري `showDraftNotes: true` إلى `false` في `script.js`، وستختفي كل الملاحظات والعناصر المؤقتة.

## زر تحميل PDF

الزر يفتح نافذة الطباعة. اختاري منها «حفظ كملف PDF». للصفحة تنسيق طباعة خاص يخفي القوائم والأزرار.

## النشر المجاني والحصول على رابط

**أسرع طريقة (Netlify Drop، بدون حساب مدفوع):**
1. افتحي https://app.netlify.com/drop
2. اسحبي مجلد المشروع كاملًا (المجلد وليس ملف ZIP) إلى الصفحة.
3. يظهر الرابط فورًا، ويمكنك تغيير اسمه من إعدادات الموقع.

**GitHub Pages:**
1. أنشئي مستودعًا عامًا جديدًا على GitHub وارفعي الملفات إليه.
2. من Settings ثم Pages اختاري الفرع `main` والمجلد `/ (root)` ثم Save.
3. الرابط يكون بهذا الشكل: `https://USERNAME.github.io/REPO-NAME/`

## ملاحظات

- لا توجد مفاتيح سرية أو بيانات شخصية حساسة في الكود.
- الخطوط تُحمَّل من Google Fonts، وفي حال عدم توفرها تُستخدم خطوط النظام تلقائيًا.
- الموقع يدعم الوضع الفاتح والليلي ويتجاوب مع الهاتف والتابلت والحاسوب.
